# Observed LinkedIn action sync
LinkedIn MDP supplies INVITATIONS, CONNECTIONS, INBOX and CHANGELOG.
Complete fresh source acquisition is validated before database access.
Invitation and connection evidence uses the existing reconcilers.
A unique successful message CREATE correlated with INBOX proves a directional DM.
Invitation notes and uncertain matches are excluded from verified DMs.
One duplicate-safe event batch records observed actions in Supabase.
Replay adds zero duplicate events.
The command is dry-run by default. Applying changes requires an explicit option.
Report research, recommendations and drafts do not become CRM events.
Scheduling and the invitation status projection remain approval proposals.
