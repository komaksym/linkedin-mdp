# Actual LinkedIn actions → CRM
Learning objective: understand why recommendations stay separate from real activity.
## Source layer
INVITATIONS · CONNECTIONS · INBOX · CHANGELOG
## Evidence layer
Complete sources first
Verified invitations and connections
Unique CREATE + INBOX match
Uncertain DMs excluded
## Persistence layer
One duplicate-safe event batch
Replay adds zero duplicates
## Boundaries
Dry-run by default
Reports remain read-only
Schedule and status projection need approval
