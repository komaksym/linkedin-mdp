# Present employer sets
One exact LinkedIn profile may have multiple explicitly present employers.
Legacy single-employer input remains supported.
One historical recipient counts once against each named present company.
Repeated invitation rows and repeated roles do not add duplicate counts.
A new recommendation requires capacity at every present employer and consumes one slot at each.
The lifetime invitation limit stays three per company across all outgoing history.
Unknown employers withhold capacity claims.
No historical employer date is invented. No report data is written to Supabase and no invitation is sent.
